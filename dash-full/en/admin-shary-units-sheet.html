Upload a units sheet

Choose the kind of units, then the project, download the template of that kind, fill it and upload it. The units are added to the chosen project.

3 · Download the template

Every kind has its own template. Row 1 holds the column names (do not change them), row 2 explains each column, and the units start at row 3 — one row per unit.
