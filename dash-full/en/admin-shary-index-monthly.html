Each area's prices and figures by type are entered on the area's own page ← "Prices & index" (not here), and show in the table below to compare. This screen enters the whole market (Egypt) only.
Add / update a month

This month is saved for this type — the figures below are the saved ones, and saving updates them in place.

Write the index and the scores in the latest month only — the area page reads the newest month that has them. Factor names and weights come from “Shary Index settings → method → area”. The scores of “all types” show for any category without its own.
One value per type + month for the whole market: saving the same month again replaces it. "All types" is the Egypt-wide line.
