عشان الخطة تشتغل بكامل قوتها

دوس على الكارت يفتحلك الصفحة اللي بتعمل منها المفتاح ← انسخه والصقه تحت الكارت ← «اربط». بنجرّبه مع الشركة ويشتغل على طول من غير المطوّر. من غيرها الخطة شغالة بداتا شاري بس.
! مفتاح الذكاء الاصطناعي (Claude أو OpenAI أو Gemini)مش مربوط — بيفتح: كتابة المقالات وتكملة الصفحات وإجابات الذكاء الاصطناعي اعمل مفتاح Gemini ↗
أو: OpenAI ↗ · Claude ↗ — اربطه من «المفاتيح والربط» دوس «Create API key» وانسخه والصقه هنا.
! Google Search Console + Analyticsمش مربوط — بيفتح: الكلمات اللي الناس بتلاقينا بيها، ترتيبنا الحقيقي، والزيارات اعمل حساب الخدمة (Service Account) ↗
نزّل ملف المفتاح (JSON) وارفعه هنا — وبعدها ضيف إيميل حساب الخدمة في سيرش كونسول وأناليتكس.
الخطوات (5)
  1. اعمل Service Account ومن تبويب Keys نزّل مفتاح JSON ↗
  2. فعّل Search Console API ↗
  3. فعّل Google Analytics Data API ↗
  4. في سيرش كونسول: الإعدادات ← المستخدمين والصلاحيات ← ضيف إيميل الـ Service Account ↗
  5. في أناليتكس: Admin ← Property access management ← ضيفه Viewer، وانسخ رقم الـ Property ↗
! Ahrefsمش مربوط — بيفتح: عدد البحث لكل كلمة وصعوبتها، كلمات المنافسين، والباك لينكس — ومنها توقعات الزيارات اعمل مفتاح Ahrefs ↗
الصفحة بتظهر لصاحب الحساب أو الأدمن بس، والـ API محتاج اشتراك فيه وحدات API.
! البحث على النت (Claude)مش مربوط — بيفتح: قراءة صفحات المنافسين والأخبار — وترتيبنا بيتقاس من سيرش كونسول اعمل مفتاح Serper ↗
سجّل (Sign up) وخد المفتاح من تبويب «API Key» — فيه 2,500 بحث ببلاش. مفتاح جوجل الرسمي (Custom Search) اتقفل للحسابات الجديدة وهيقف 1 يناير 2027.
! SerpAPI (ملخصات جوجل بالذكاء الاصطناعي)مش مربوط — بيفتح: هل جوجل بيطلّع ملخص AI للكلمة، وشاري مذكور فيه كمصدر ولا المنافس — وترتيبنا في نفس الطلب اعمل مفتاح SerpAPI ↗
سجّل دخول (أو اعمل حساب) والمفتاح بيظهر في نفس الصفحة.
