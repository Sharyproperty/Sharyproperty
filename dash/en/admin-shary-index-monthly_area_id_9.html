Shary Index: monthly prices

Average price per m² month by month, per area and property type — feeds the price trend chart and the monthly / yearly change of the Shary Index page
Add / update a month
Write the index and the scores in the latest month only — the area page reads the newest month that has them. Factor names and weights come from “Shary Index settings → method → area”. The scores of “all types” show for any category without its own.
One value per area + type + month: saving the same month again replaces it. "Whole market" + "All types" is the Egypt-wide line.
