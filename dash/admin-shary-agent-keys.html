المفاتيح والربط

دوس على الكارت يفتحلك الصفحة اللي بتعمل منها المفتاح ← انسخه ← الصقه تحته ← «اربط». بنجرّبه مع الشركة نفسها على طول: لو صح بيشتغل في الموقع والإيجنت فورًا — من غير المطوّر.

🔒 المفاتيح في أمانبتتحفظ متشفّرة وما بتظهرش تاني (بيبان آخر 4 حروف بس)، الأدمن الرئيسي بس اللي يربط أو يشيل، كل تغيير بيتسجل في السجل باسم اللي عمله، والإيجنت نفسه ما يقدرش يشوفها. ما تبعتش مفتاح في الشات أو الإيميل.

الإيجنت (الفهم والكتابة والتحليل) + Shary AI على الموقع + نسخ التصميمات باللغة التانية. واحد بس كفاية.

دوس «Create API key» وانسخه والصقه هنا.
! OpenAI (ChatGPT)مش مربوط — بيفتح: بديل لـ Gemini للإيجنت وShary AI اعمل مفتاح OpenAI ↗
دوس «Create new secret key» وانسخه — بيظهر مرة واحدة بس.
! Claudeمش مربوط — بيفتح: بديل للإيجنت اعمل مفتاح Claude ↗
دوس «Create key» وانسخه — بيظهر مرة واحدة بس.

البحث والسيو

ترتيب شاري في جوجل والمنافسين، حجم البحث والباك لينكس، وملخصات جوجل بالذكاء الاصطناعي.
! بحث جوجل (Serper)مش مربوط — بيفتح: ترتيبنا ومين المنافس الأول في كل كلمة، الأخبار، وقراءة صفحات المنافسين اعمل مفتاح Serper ↗
سجّل (Sign up) وخد المفتاح من تبويب «API Key» — فيه 2,500 بحث ببلاش. مفتاح جوجل الرسمي (Custom Search) اتقفل للحسابات الجديدة وهيقف 1 يناير 2027.
! ملخصات جوجل AI (SerpAPI)مش مربوط — بيفتح: جوجل بيطلّع ملخص AI للكلمة؟ وشاري مذكور فيه كمصدر ولا المنافس اعمل مفتاح SerpAPI ↗
سجّل دخول (أو اعمل حساب) والمفتاح بيظهر في نفس الصفحة.
! Ahrefsمش مربوط — بيفتح: حجم البحث وصعوبة كل كلمة، كلمات المنافسين، والباك لينكس — ومنها توقعات الزيارات اعمل مفتاح Ahrefs ↗
الصفحة بتظهر لصاحب الحساب أو الأدمن بس، والـ API محتاج اشتراك فيه وحدات API.
عندك مفتاح بحث جوجل القديم (Custom Search)؟ ! بحث جوجل الرسمي (Custom Search) — للحسابات القديمةمش مربوط — بيفتح: نفس شغل Serper لو عندك المفتاح القديم افتح محرك البحث بتاعك ↗
للي عنده المفتاح القديم بس: رقم المحرك (Search engine ID) من هنا، والمفتاح من Google Cloud. جوجل هيقفل الخدمة دي 1 يناير 2027. Google Cloud ↗

جوجل سيرش كونسول وأناليتكس

الكلمات اللي الناس بتلاقينا بيها، ترتيبنا الحقيقي، والزيارات.
! سيرش كونسول + أناليتكس (حساب خدمة جوجل)مش مربوط — بيفتح: الكلمات اللي الناس بتلاقينا بيها، ترتيبنا الحقيقي، والزيارات اعمل حساب الخدمة (Service Account) ↗
الملف اللي نزل من Google Cloud ← Keys ← Add key ← JSON.
زي ما هو مكتوب في سيرش كونسول: sc-domain:shary.eg أو https://shary.eg/
أرقام بس — من Admin ← Property details.
نزّل ملف المفتاح (JSON) وارفعه هنا — وبعدها ضيف إيميل حساب الخدمة في سيرش كونسول وأناليتكس.
الخطوات (5)
  1. اعمل Service Account ومن تبويب Keys نزّل مفتاح JSON ↗
  2. فعّل Search Console API ↗
  3. فعّل Google Analytics Data API ↗
  4. في سيرش كونسول: الإعدادات ← المستخدمين والصلاحيات ← ضيف إيميل الـ Service Account ↗

قراءة الطلبات اللي بتيجي على الإيميل، وإرسال التقارير والإشعارات.
! قراءة الإيميل (طلبات العملاء)مش مربوط — بيفتح: الإيجنت بيقرا الطلبات وشيتات المطورين اللي بتيجي على الإيميل (قراءة بس) افتح إعدادات الإيميل ↗
لإيميل Hostinger اكتب: {imap.hostinger.com:993/imap/ssl}INBOX
Emails ← Manage ← Connect Apps & Devices — القراءة (IMAP): imap.hostinger.com بورت 993 (SSL).
! إرسال الإيميلات (SMTP)مش مربوط — بيفتح: التقارير والإشعارات وإيميلات الموقع بتطلع من الإيميل ده افتح إعدادات الإيميل ↗
465 (SSL) أو 587 (TLS).
عادة نفس الإيميل اللي فوق.
Emails ← Manage ← Connect Apps & Devices — الإرسال (SMTP): smtp.hostinger.com بورت 465 (SSL)، أو 587 (TLS).

واتساب وزووم

رسايل الإيجنت والتقارير لرقم الفريق، ورسايل وتذكير ميتنج Shary AI ولينك الزووم.
! واتساب (WhatsApp Cloud API)مش مربوط — بيفتح: رسايل الإيجنت والتقارير لرقم الفريق، ورسايل وتذكير الميتنج افتح تطبيق واتساب في Meta ↗
رقم طويل من WhatsApp ← API Setup (مش رقم التليفون).
رسالة معتمدة في WhatsApp Manager فيها 3 متغيرات: {{1}} العنوان · {{2}} الملخص · {{3}} اللينك.
فاضي = رسالة الميتنج نفسها.
الرقم التعريفي (Phone number ID) من WhatsApp ← API Setup، والتوكن الدائم من System users، والرسايل المعتمدة من WhatsApp Manager.
الخطوات (3)
  1. اعمل App (Business) وضيف له WhatsApp — وانسخ Phone number ID من API Setup ↗
  2. توكن دايم: Business settings ← System users ← Admin ← Generate token (whatsapp_business_messaging + whatsapp_business_management) ← Never ↗
  3. الرسايل المعتمدة (Templates): WhatsApp Manager ← Message templates ↗

للمطوّر (اختياري)

المفاتيح ممكن تتحط برضو في ملف .env على السيرفر بنفس الأسامي (GEMINI_API_KEY ، SERPER_API_KEY ، AHREFS_API_KEY ، WHATSAPP_TOKEN …). لو المفتاح موجود هنا وفي .env، اللي هنا هو اللي بيشتغل — ولو اتشال من هنا بيرجع للي في .env.
