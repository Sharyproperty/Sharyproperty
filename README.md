# Shary — Front-end

فرونت صفحات موقع شاري (HTML + Tailwind CSS)، جاهز للربط بالباك إند.

| الفولدر | المحتوى |
|---|---|
| [`blog/`](blog/) | صفحة المدونة + صفحة المقال (موبايل وديسك توب، عربي وإنجليزي) — التفاصيل في [`blog/README.md`](blog/README.md) |

كل فولدر فيه نسخة HTML جاهزة للفتح في المتصفح، ونسخة Blade لـ Laravel، وملف شرح للربط.
