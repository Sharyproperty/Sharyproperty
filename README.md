# Shary — Front-end

فرونت صفحات موقع شاري (HTML + Tailwind CSS + Laravel Blade)، جاهز للربط بالباك إند. كل صفحة في فولدر لوحدها باسمها:

| الفولدر | المحتوى |
|---|---|
| [`area/`](area/) | صفحة المنطقة (موبايل وديسك توب، عربي وإنجليزي) بالفلاتر والترتيب — التفاصيل في [`area/README.md`](area/README.md) |
| [`developer/`](developer/) | صفحة المطور (موبايل وديسك توب، عربي وإنجليزي) — التفاصيل في [`developer/README.md`](developer/README.md) |
| [`search/`](search/) | صفحة نتايج البحث (موبايل وديسك توب، عربي وإنجليزي): البحث العام + بحث نوع ومنطقة، وحدات وكمبوندات، الفلاتر، خانة البحث واقتراحاتها، والتحميل وأنت نازل — التفاصيل في [`search/README.md`](search/README.md) |
| [`blog/`](blog/) | صفحة المدونة + صفحة المقال (موبايل وديسك توب، عربي وإنجليزي) — التفاصيل في [`blog/README.md`](blog/README.md) |

كل فولدر فيه:

- `html/` — الصفحات جاهزة للفتح في المتصفح، ومعاها الـ CSS المبني والسكربتات والصور.
- `laravel/` — ملفات Blade والكنترولر والـ routes وبيانات تجريبية وملفات Tailwind (`tailwind.config.js` + `resources/css/app.css`).
- `README.md` — شرح الربط.

الملفات المشتركة (الهيدر، الفوتر، فورم طلب الاجتماع، `layouts/site.blade.php`، `site-chrome.js`، `app.css`، `tailwind.config.js`) هي هي في الأربع فولدرات، فلو هتركّب أكتر من صفحة انسخ الفولدرات فوق بعض وهتتدمج من غير تعارض.
